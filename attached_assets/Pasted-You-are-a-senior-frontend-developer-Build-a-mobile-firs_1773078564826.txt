You are a senior frontend developer.

Build a **mobile-first Progressive Web App (PWA) UI** for a **customer loyalty / point accumulation system** used by a small shop.

IMPORTANT GOALS:

* UI must be **simple, fast, and optimized for phone usage**
* Use **vanilla HTML, CSS, and JavaScript only**
* No frameworks (no React/Vue)
* Clean and modern UI
* Mobile-first layout
* Works well as a **PWA installed on phone**

Create a **complete UI prototype** with placeholder data.

---

APP STRUCTURE

The app has 3 main screens:

1. POS main screen
   route: `/pos`

2. POS customer detail screen
   route: `/pos/customer`

3. Customer share page
   route: `/share/<customerId>`

Use a **simple router based on window.location.pathname**.

---

FEATURES OVERVIEW

The system allows shop staff to:

* search customer by phone
* scan customer QR
* create new customer
* add points
* edit points
* redeem reward
* share customer link

Customers can:

* open shared link
* view their points
* see reward progress
* show QR code for scanning
